# Notas de la versión 0.2.0 Alpha Workflow Studio

Esta es una versión independiente. No reemplaza ni modifica la carpeta `0.1.2`.

## Lo más importante

- El editor visual ahora tiene biblioteca buscable, arrastre, duplicado, historial, validación, zoom y exportación PNG.
- Las macros se pueden compartir individualmente y sus pasos son más fáciles de reorganizar o reutilizar.
- El monitor ya sirve para análisis: filtra, pausa la vista, copia resultados y exporta CSV.
- Los perfiles existentes conservan compatibilidad de esquema.

## Recomendación de actualización

1. Conserva la versión anterior.
2. Ejecuta `setup.bat` dentro de esta carpeta.
3. Inicia con `run.bat` o usa `run_console.bat` si necesitas ver el diagnóstico.
4. Importa tus perfiles `.ibiki` desde la página **Perfiles**.

## Qué no se presenta como terminado

No se incluyen integraciones ficticias, perfiles en la nube, Rapid Trigger físico ni separación real por teclado. Esos puntos necesitan servicios externos, hardware o una arquitectura de controlador distinta.
