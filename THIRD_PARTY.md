# Componentes externos

El instalador descarga estos paquetes desde PyPI dentro de `.venv`:

| Paquete | Uso | Licencia declarada por el proyecto |
|---|---|---|
| PySide6 | Interfaz Qt | LGPL-3.0 / GPL / comercial |
| keyboard | Hooks y emisión de teclado | MIT |
| psutil | Procesos y perfiles automáticos | BSD-3-Clause |
| pywin32 | Integración Win32 | PSF |
| pyperclip | Portapapeles | BSD |

Las licencias completas pertenecen a sus respectivos proyectos y se instalan con sus distribuciones. Ibiki Key no usa ni requiere el paquete externo `mouse`; su backend de mouse está incluido en el código fuente.
